使用须知

  1. 写经过。写你看到了什么、做了什么。不确定的地方请注明“猜测”。
  2. 不填隐私。邮箱、密码、API Key、订单号、手机号、微信或 QQ、链接、证件号码都不要填。系统检测到会直接拦下。
  3. 保存好凭据。立碑后会得到一组编号和密钥，用来修改和撤回。它只显示一次，丢了没法找回。
  4. 这里不谈这些。买卖账号、拼车合租、中转代理、代充代付、翻墙节点、防封技巧、解封服务。相关内容一律不通过。
  5. 对事不对人。不点名攻击任何个人，包括厂商的员工。
  6. 想申诉，请走官方渠道。本站没法帮你解封，见“官方申诉入口”。

会公开的内容

审核通过后，墙上会显示：代号、署名、厂商、事件种类、套餐、注册时间（按你选的精度）、出事日期、经过、墓志铭、申诉状态、碑脚样式、献花数和立碑时间。

不会收集的内容

不需要注册，不要邮箱、手机号或真实姓名。本站不设置 Cookie，不使用第三方统计、广告或追踪脚本。人机验证使用 Cloudflare Turnstile。

IP 地址

为了防刷，服务器会用 IP 计算一个加盐的哈希值做次数限制，哈希每天更换，不保存原始 IP。

凭据

凭据由编号和密钥组成。服务器只保存密钥的哈希，没人能替你找回。你可以选择让浏览器记住它，它只存在你这台设备的这个浏览器里。

审核

所有投稿和修改都由站长人工审核，通过后才公开。审核中的内容不会出现在墙上和统计里。

撤回

撤回后，碑会从墙上和统计中消失，碑文会从数据库里清空。已经被别人看到、截图或转发的内容，本站无法收回。

保存多久

  • 公开的碑：一直保留，直到你撤回或被隐藏。
  • 没通过审核的投稿：30 天后删除。
  • 已处理的举报：90 天后删除。
  • 防刷记录：2 天后删除。
