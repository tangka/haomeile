`community-cases.json` 是经复核的导入清单；分产品研究文件保留来源、可见后续与证据边界。收录的是公开原帖的原创编辑摘要，**不是原作者向本站提交的投稿，也不是对账号处置的独立事实核验**。页面按浏览器语言显示编辑摘要，本站用户投稿的原文不自动翻译。

- 中英文摘要一律第三人称，中文以“原帖作者说，”开头，英文以“The original poster says”开头；只写原帖里看得到的事实，作者的猜测写明是作者猜测。
- 每条提供原帖链接、原帖发布日期和产品；卡片标题是编辑标题，不冒充原作者昵称。
- 仅在原帖能确定具体事发日时填写事件日期。
- 套餐只用原帖明确档位；恢复/申诉结果按原帖可见更新描述，不代表当前状态。
- 不复制邮箱、账号标识、工单号或长段原文；不记录推测为确定封号原因。
- 社区案例单独计数，排除于本站自愿上报数及 30 天曲线；初始献花数为 0。
- 导入前备份；使用生产程序的离线 `import-community` 命令。按来源身份幂等，重跑不能恢复隐藏、撤回记录。原作者可通过详情页举报请求更正或删除。
